# IVI-Detect · 工业表面缺陷智能检测平台

面向工业质检现场的表面缺陷检测 / 字符识别 / 尺寸测量一体化桌面工具。
纯本地离线运行（Python + OpenCV），不依赖 GPU 与网络，双击即可演示。

## 1. 解决什么问题

工业表面质检的现场痛点不是"没有算法"，而是：

1. **光照不均**：环形光源偏心 + 工件暗角，全局阈值在暗区必然漏检；
2. **低对比缺陷**：油污、水渍与材质纹理灰度重叠，人眼都要换角度才看得见；
3. **漏检与误检代价不对称**：一件废品流出 ≫ 一件良品被多复检一次，
   按 F1 最优选的阈值在产线上是错的。

本项目针对这三点给出可量化验证的改进，而不是"换一个更大的模型"。

## 2. 三处具体改动（相对基线）

| 编号 | 改动 | 解决的问题 | 单独消融后的 F1 |
|---|---|---|---|
| C1 | 光照归一化：81×81 中值背景估计后差分 | 光照梯度导致的暗区漏检 | 0.107（去掉即崩） |
| C2 | 双频通道：多尺度黑帽(7/15/25) + 残差低通(σ=2.5)，并集 | 细划痕与大面低对比油污不能用一个尺度兼顾 | 0.605 |
| C3 | 自适应阈值(mean+k·MADσ) + 代价加权判定 + 缺陷分级 | 换材质要重调参；F1 最优 ≠ 产线最优 | — |
| C4 | 缺陷类型粗分类（划痕/凹坑/污渍/油污） | 只报"有问题"不够，产线要知道是什么问题 | 测试划分准确率 97.1% |
| C5 | 输入尺度自适应（按标定重采样到 12 px/mm） | 换相机/改工作距离后参数全部失效 | 2× 输入召回 68.6%→90.5% |
| C6 | 无监督异常检测（PatchCore-lite，106 张良品训练） | 新产线没有标注时无法启用 | F1 0.667 · 良品误报 13.9% · 189 ms |

配套工程处理：
- **各向异性闭运算**：4 个方向线性结构元替代 5×5 圆核，避免把 1~2 px 划痕整段抹掉；
- **相对反差细化（滞后阈值）**：削掉低频通道在缺陷周边晕开的过渡带，面积量化更接近真值。

## 3. 实测结果

同一数据集（160 张 640×480，124 张有缺陷 / 36 张良品，共 310 处缺陷），
同一后处理、同一匹配准则（IoU≥0.30 或预测框中心落在真值连通域内）：

| 方案 | 精确率 | 召回率 | F1 | 漏检率 | 良品误报率 | 耗时 |
|---|---|---|---|---|---|---|
| 基线 Otsu（已扫参取最优） | 24.1% | 38.2% | 0.295 | 61.8% | 100% | 8.4 ms |
| **改进方案** | **98.2%** | **90.7%** | **0.943** | **9.3%** | **0%** | 35.6 ms |

逐类召回：污渍 98.8% · 油污 96.6% · 凹坑 91.4% · **划痕 71.0%（短板）**

### 新增能力（v1.1）

| 能力 | 指标 | 口径 |
|---|---|---|
| 缺陷类型粗分类 | 全量 96.1%（280 处）· 测试划分 **97.1%** | 阈值在偶数图搜索、奇数图报告，避免自评 |
| 逐类分类准确率 | 划痕 100% · 油污 96.4% · 凹坑 95.3% · 污渍 94.0% | 同上 |
| 输入尺度自适应 | 2× 输入：68.6% → **90.5%**；0.5× 输入：86.2% → **97.7%** | 60 张图，缩放后与缩放真值比对 |

复现：`python -m tools.eval_extra` → `out/extra_report.json`

### 两种范式对照（同一评测集、同一匹配准则）

| 方案 | 需要标注 | 精确率 | 召回率 | F1 | 良品误报 | 单帧 |
|---|---|---|---|---|---|---|
| 规则链路（默认） | 分类阈值需要 | 98.2% | 90.7% | **0.943** | 0% | 34 ms |
| 无监督（106 张良品） | **不需要** | 87.6% | 53.8% | 0.667 | 13.9% | 189 ms |
| 基线 Otsu | 不需要 | 24.1% | 38.2% | 0.295 | 100% | 8 ms |

无监督版训练用 **106 张良品图**（评测集 36 张 + `data/train_ok` 单独生成的 70 张，训练集与评测集分离），20.8 s，特征为 5 维 patch 统计量，特征库 12000 条，阈值由良品分数 95 分位校准。增加训练图后误报持平、召回略降（58.8%→53.8%），说明「多」不等于「好」，关键是良品图与产线工况同分布。
定位：**无标注冷启动用无监督筛候选，定型产线用规则链路**。切换入口在界面「算法方案」。

复现：`python -m tools.unsup_eval` → `out/unsup_report.json` + `out/anomaly_model.npz`

判定阈值权衡（漏检代价 : 误检代价 = 10 : 1）：

| 取值策略 | score_thr | 漏检 | 误检 | 加权代价 |
|---|---|---|---|---|
| F1 最优 | 0.60 | 39 | 2 | 392 |
| **代价最优** | 0.55 | 17 | 32 | **202（−48%）** |

## 4. 运行

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
pip install -r requirements.txt
python app.py                     # 启动界面
```

复现评测与配图：

```bash
python -m tools.make_demo         # 生成 OCR/测量演示样例
python -m tools.evaluate          # 输出 out/eval_report.json + 图
```

`rapidocr-onnxruntime` 缺失时，字符识别自动回退到内置模板匹配（精度会下降，
界面右下角会显示当前引擎），不影响缺陷检测与尺寸测量。

## 6. 已知限制（答辩时必须讲清）

1. **数据集为合成数据**：难度可控、真值精确，但纹理分布与真实产线仍有差距，
   结论需在真实工件上复验；`px_per_mm=12` 为虚构标定值。
2. **划痕召回偏低（71.0%）**：宽度 1~2 px 的划痕与拉丝纹理同频，
   在当前分辨率下不可分，需更高分辨率相机或低角度暗场照明。
3. **面积量化中位误差约 26~32%**：划痕因断点桥接被高估；小缺陷边界受形态学影响。
4. **跨分辨率已缓解但非万能**：尺度自适应把 2× 输入的召回从 68.6% 拉到 90.5%，但缩放本身会丢信息，0.5× 输入仍有 2.3% 漏检。
5. **不适用**：强反光镜面、曲率变化大的工件、缺陷与图案（印刷/纹理）同尺度混合的场景。
6. 字符识别依赖 ONNX 模型，模板匹配兜底精度有限；曲面喷码需更高阶模型。
