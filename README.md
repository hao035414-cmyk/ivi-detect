# IVI-Detect · 工业表面缺陷智能检测平台

面向工业质检现场的表面缺陷检测 / 字符识别 / 尺寸测量一体化桌面工具。
纯本地离线运行（Python + OpenCV），不依赖 GPU 与网络，双击即可演示。

> 版本：v1.0（2026-11-22）

## 1. 解决什么问题

工业表面质检的现场痛点不是"没有算法"，而是：

1. **光照不均**：环形光源偏心 + 工件暗角，全局阈值在暗区必然漏检；
2. **低对比缺陷**：油污、水渍与材质纹理灰度重叠，人眼都要换角度才看得见；
3. **漏检与误检代价不对称**：一件废品流出 ≫ 一件良品被多复检一次，
   按 F1 最优选的阈值在产线上是错的。

本项目针对这三点给出可量化验证的改进，而不是"换一个更大的模型"。

## 2. 三处具体改动（相对基线）

| 编号 | 改动 | 解决的问题 | 单独消融后的 F1 |
|---|---|---|---|
| C1 | 光照归一化：81×81 中值背景估计后差分 | 光照梯度导致的暗区漏检 | 0.107（去掉即崩） |
| C2 | 双频通道：多尺度黑帽(7/15/25) + 残差低通(σ=2.5)，并集 | 细划痕与大面低对比油污不能用一个尺度兼顾 | 0.605 |
| C3 | 自适应阈值(mean+k·MADσ) + 代价加权判定 + 缺陷分级 | 换材质要重调参；F1 最优 ≠ 产线最优 | — |

配套工程处理：
- **各向异性闭运算**：4 个方向线性结构元替代 5×5 圆核，避免把 1~2 px 划痕整段抹掉；
- **相对反差细化（滞后阈值）**：削掉低频通道在缺陷周边晕开的过渡带，面积量化更接近真值。

## 3. 实测结果

同一数据集（160 张 640×480，124 张有缺陷 / 36 张良品，共 310 处缺陷），
同一后处理、同一匹配准则（IoU≥0.30 或预测框中心落在真值连通域内）：

| 方案 | 精确率 | 召回率 | F1 | 漏检率 | 良品误报率 | 耗时 |
|---|---|---|---|---|---|---|
| 基线 Otsu（已扫参取最优） | 24.1% | 38.2% | 0.295 | 61.8% | 100% | 8.4 ms |
| **改进方案** | **98.2%** | **90.7%** | **0.943** | **9.3%** | **0%** | 35.6 ms |

逐类召回：污渍 98.8% · 油污 96.6% · 凹坑 91.4% · **划痕 71.0%（短板）**

判定阈值权衡（漏检代价 : 误检代价 = 10 : 1）：

| 取值策略 | score_thr | 漏检 | 误检 | 加权代价 |
|---|---|---|---|---|
| F1 最优 | 0.60 | 39 | 2 | 392 |
| **代价最优** | 0.55 | 17 | 32 | **202（−48%）** |

## 4. 运行

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
pip install -r requirements.txt
python app.py                     # 启动界面
```

复现评测与配图：

```bash
python -m tools.make_demo         # 生成 OCR/测量演示样例
python -m tools.evaluate          # 输出 out/eval_report.json + 图
```

`rapidocr-onnxruntime` 缺失时，字符识别自动回退到内置模板匹配（精度会下降，
界面右下角会显示当前引擎），不影响缺陷检测与尺寸测量。

## 6. 已知限制（答辩时必须讲清）

1. **数据集为合成数据**：难度可控、真值精确，但纹理分布与真实产线仍有差距，
   结论需在真实工件上复验；`px_per_mm=12` 为虚构标定值。
2. **划痕召回偏低（71.0%）**：宽度 1~2 px 的划痕与拉丝纹理同频，
   在当前分辨率下不可分，需更高分辨率相机或低角度暗场照明。
3. **面积量化中位误差约 26~32%**：划痕因断点桥接被高估；小缺陷边界受形态学影响。
4. **不适用**：强反光镜面、曲率变化大的工件、缺陷与图案（印刷/纹理）同尺度混合的场景。
5. 字符识别依赖 ONNX 模型，模板匹配兜底精度有限；曲面喷码需更高阶模型。
